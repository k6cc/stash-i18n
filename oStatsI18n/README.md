# oStatsI18n

统计页 O 统计 + 观看时长追踪插件（O Stats 的多语言重构）。纯 UI + Python 后端：把今日与本周的 O 数、连续天数、观看时长/视频数与平均分钟/O 卡片，全部时间与纪录行，O 次数 / 观看时长柱状图与 O 日历 / 观看日历热力图，亮点（含最 O 图片）、表现最佳排名、媒体库分区，以及「当日回顾」时间线注入统计页；观看时长与图片 O 的时间按日记录并跨设备同步。

## 依赖

- Stash 界面语言为中文时 UI 显示中文，否则英文（i18n 桥接失败降级英文）
- Python（`osaver.py`，由页面经 `runPluginOperation` 调用以保存/读取观看时长与图片 O 的时间）

## 安装

复制 `oStatsI18n` 文件夹到 Stash 插件目录，重启 Stash，进入统计页即生效。

## 核心机制

- 观看时长：按播放器自身进度计量（暂停、缓冲、拖动与休眠不计入），每分钟及停止/离开时经 `runPluginOperation` 发给 `osaver.py`，由服务端按日累加写入 `odata.json`（带锁文件与原子替换，多标签页/多设备不互相覆盖）
- 图片 O：Stash 只记录图片 O 的次数、不记时间，插件拦截 Stash 自身的图片 O 请求，在确认成功后把每次点击的时间交给 `osaver.py` 记录（与观看时长同一数据文件）
- O 统计：按 `o_history` 时间戳构建日期映射，一次遍历供全部卡片/图表复用
- 样式：随插件加载的 `oStatsI18n.css` 预先隐藏 Stash 自带的统计行，页面统计全部由插件绘制（类名前缀 `os-` 与上游一致）
- 插件设置：各区块（今日与本周统计行、全部时间与纪录行、亮点、活动图表含两张日历热力图、表现最佳、当日回顾、媒体库）的显示/隐藏、是否统计图片 O、当日回顾时间线是否显示观看标记等开关，在 Stash 插件设置页配置（键名与上游一致，仅 displayName/描述为中文）
- 图表配对：O 图表/日历与观看图表/日历可切换堆叠或并排显示，选择记在浏览器本地（`oStatsI18n_` 前缀）
- 本周对比：每张今日卡片下方给出本周合计、逐日柱状图（本周实心、上周空心）及与上周、通常一周的差值，可在「今日与本周」标题栏切换显示（选择记在浏览器本地）
- 表现最佳：按 O 数或观看次数对演员、标签、工作室排名（每项取前九），可切换查看对象与排序
- 导出格式：`{"version":"4.0","data":{"YYYY-MM-DD":{"seconds":N,"o_count":N}},"image_o_history":{"图片ID":["ISO 时间",…]}}`（导入兼容 4.0、3.0、2.0 与更早的纯数字格式；旧文件不带图片 O 时保留已记录的数据）

## 注意事项

- `odata.json` 为运行时数据（不随仓库发布），删除后从零开始记录；旧版的 `watch_data.json` 在首次写入后自动转为 `watch_data.json.bak`
- 与官方 O Stats 并存时各自独立存储（localStorage 键、数据路径、设置键均以 `oStatsI18n` 命名）
- 中文界面下时间使用 24 小时制，日期使用中文格式；英文界面保持原 12 小时制与 `MM/DD/YYYY`

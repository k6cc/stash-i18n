# LockdownI18n

把 Stash 锁定在一位演员、一个工作室或一个标签上，直到你「脱身」（Lockdown 的汉化版，中文名「锁局」）。玩法接近 roguelike 一局：选锁定对象、选脱身方式、再叠加热度（heat）条件，条件越难分数越高。汉化版只改界面文案，功能与数据行为沿用上游。

## 依赖

- Stash 界面语言为中文时显示中文，否则英文（i18n 桥接失败降级英文）
- 无 Python 后端、无额外依赖；历史与排行榜可选地存入 Suite Data

## 安装

复制 `LockdownI18n` 文件夹到 Stash 插件目录，重启 Stash。顶栏出现「锁局」入口，打开即为插件自身的页面（新一局 / 排行榜 / 历史三个标签页）。

## 核心机制

- 锁定：目标（及其下属）的页面与场景/图片/图库可以访问，其他路径一律弹回；锁定状态保存在 Stash 插件配置里，跨设备生效，本机另存 localStorage 副本
- 目标：一名演员、一对双人（两位演员，任一位的场景都算）、一个工作室（含下级工作室）或一个或多个标签（AND/OR）；仅有图片的目标也能锁（配「完成」或按锁定时间的「计时」）
- 脱身：Finish（O 即脱身）、Timer（计时，按观看时长或锁定时长）、Edge（看满设定时长且不 O）。Edge 到点后分数入账，可就此结束或进入「加时」（超出目标时长后不再加分，锁定持续到一次 O 或「停止加时」）
- 热度：跳过配额、轮盘随机、坚持到底、禁止快进（含隐藏时间轴预览）、盯着画面（离开超过 5 秒停表并按每 2 秒扣 1 分）、仅未看过、慢热、隐藏目标、玩具主导（Intiface Sync 的 Goon 模式）、单一场景、严苛失误等条件；每点热度给分数加 20%
- 对局中的牌：每看满 10 分钟来一张「坚持」牌（盯着画面 2 分钟 +30，或 Stay 5 / Stay 10），标签牌会打开带该标签的场景，有跳过配额时还有跳过牌（最多 3 张）；对局后段会来「竞赛」牌（3 分钟内射出来 +100，否则 −50）。开局前的第 4 步可先挑好手牌
- 记录：每局的脱身方式、跳过/失误/加时、时长与分数进入历史与排行榜（名人堂，按脱身方式各取前 20），可存为预设（preset）复用整套配置；结束后还会显示本局刷新了哪些纪录
- 推荐演员（仅演员）：为你推荐 / 久未光顾 / 待看积压 / 发现新人 / 给我惊喜 / 双人六类榜单，每天与「换一批」时轮换；双人榜给出搭配伙伴，也可作为随机抽取的来源
- 身体数据（Body stats）：锁定到演员（或双人）且装了 Performers Toolkit 时，页面多一个「身体数据」标签页
- 图片计分：盘中在 Slideshow、图片页或 Stash 查看器里看满 3 秒的新图片每张加 1 分（每盘最多 100 张，热度前计入），已出局的对局计过的图片不再计分
- 新颖度与下一局建议：最近 5 盘没出现的条件每项加 3%（最多 15%），开局时固定；出局后建议下一个可尝试的条件，可一键按此开局
- 跨设备同步与重试：多标签页只有一个负责轮询，切换标签页时立即同步；已结束但未写入 Stash 的对局先存在本地，之后按退避间隔重试，写入失败不再丢分
- 与 Slideshow 联动可播放被锁定对象的图片
- 跟随主题：颜色取自 Stash 当前主题（装 Flexoki 主题插件时用 Flexoki 配色，否则从当前主题的背景/卡片/文字推导，浅色主题同样适用），随主题切换自动重算

## 上游同步

- 本目录是 [allisless0/stash-plugins](https://gitlab.com/allisless0/stash-plugins) 的 `plugins/Lockdown`（MIT）在**文案层**的本地化派生，功能逻辑沿用上游实现，版权归上游作者
- 上游发布新版后的同步流程与基线记账见仓库根 [UPSTREAM.md](../UPSTREAM.md) 与 `scripts/upstream-diff.ps1`
- 该上游仓库同时托管多个插件（Insights、Slideshow、Suite Data 等），同步时只取 `plugins/Lockdown`

## 注意事项

- 与上游原版 Lockdown **不建议同时启用**：两者都会注册自己的页面路由并执行锁定逻辑。若并存，本汉化版的页面地址为 `/lockdown-i18n`（上游为 `/lockdown`）
- 插件 ID、localStorage 键（`lockdownI18n*`）、Suite Data 中的记录键均以 `LockdownI18n` 命名，与上游原版各自独立
- 版本号采用「上游版本-汉化修订号」：上游 2.11.0 → 本仓库 2.11.0-1
